# HI3322 SDK placeholder

This directory mirrors the WS63 SDK layout consumed by the OpenHarmony
`liteos_m` build. When integrating the real HI3322 SDK, populate:

- `kernel/liteos/liteos_v208.5.0/hi3322-liteos-app/libinterrupt.a`
  — HiSilicon PLIC CSR-based interrupt lib (himideerv200 equivalent).
    NOTE: the current liteos_m port does NOT link libinterrupt.a. The CLIC
    driver is implemented from scratch in
    `device/board/hihope/hi3322/liteos_m/board/hi3322_clic.c` (mirroring
    hs-fbb riscv_lcmp_clic.c), and `interrupt_stub.c` provides an OsIntHandle
    stub for any stray references. The entry below is retained for the day a
    real SDK drop replaces the from-scratch driver.
- `open_source/libboundscheck/include/{securec.h,securectype.h}`
  — securec headers (referenced by `liteos_m/board/BUILD.gn:public` config)
- `output/hi3322/acore/boot_bin/{loaderboot_signed.bin,ssb_signed.bin,
   ssb_backup_signed.bin,recovery_signed.bin,seliteos_signed.bin}`
   — pre-signed HI3322 bootloader images for the 16 MB flash layout
- `output/hi3322/acore/param_bin/rootkey_partition_cfg.bin`
   — signed partition table + root key (written to flash base 0x26000000)
- `output/hi3322/acore/nv_bin/hi3322_all_nv.bin`
   — NV partition bin (generated by `build/config/target_config/hi3322/build_nvbin.py`)
- `tools/bin/sign_tool/sign_tool_pltuni`
  — image signing tool
- `tools/bin/compiler/riscv/cc_riscv32_musl_100/cc_riscv32_musl_fp/lib/gcc/riscv32-linux-musl/7.3.0/libgcc.a`
  — riscv32 musl gcc libgcc (referenced by `liteos_m/board/BUILD.gn:public` ldflags)
- `tools/pkg/packet_create.py`
  — fwpkg packet builder (exposes `packet_bin(out, entries)`)
- `build/config/target_config/hi3322/sign_config/{ec_bp256_flash_private_key.pem,
   ec_bp256_app_private_key.pem}`
  — signing keys for `pack_fwpkg.sh`

These paths are referenced from:
- `device/board/hihope/hi3322/liteos_m/board/BUILD.gn` (libclang_rt.builtins-riscv32.a
  via the `board_clang_rt_lib` board config var; libinterrupt.a is NOT linked — see above)
- `device/board/hihope/hi3322/liteos_m/board/pack_fwpkg.sh` (sign_tool, bins, packet_create)
- `vendor/hihope/hi3322/config.json` (`third_party_dir` → `open_source`)
